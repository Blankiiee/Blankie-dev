# TariffAdvisor

Десктопний застосунок на C# (Windows Forms, .NET 8) для підбору найвигіднішого тарифу мобільного зв'язку на основі індивідуальних потреб користувача.

---

## Мета проєкту

Користувач вводить свій місячний обсяг використання послуг (гігабайти, хвилини, SMS), а застосунок розраховує вартість кожного тарифу з урахуванням абонплати та платежів за перевищення лімітів, після чого рекомендує найвигідніший варіант.

Проєкт створено як навчальну роботу для демонстрації навичок розробки десктопних застосунків на .NET та роботи з Windows Forms.

---

## Можливості

- Введення параметрів використання: інтернет (ГБ), хвилини дзвінків, SMS.
- Розрахунок вартості кожного тарифу з урахуванням перевищення лімітів.
- Таблиця з порівнянням усіх тарифів (абонплата та підсумкова вартість).
- Автоматична рекомендація найвигіднішого тарифу.
