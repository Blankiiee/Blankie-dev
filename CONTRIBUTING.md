# Contributing to TariffAdvisor

Дякуємо за інтерес до проєкту! Цей документ описує, як правильно долучитися до розробки.

---

## Як створити гілку

1. Зробіть Fork репозиторію.
2. Клонуйте свій форк локально:
git clone https://*************/TariffAdvisor.git
cd TariffAdvisor

3. Створіть нову гілку від `main`:
git checkout -b feat/назва-зміни

Приклади назв гілок:
- `feat/add-new-tariff` — нова функціональність
- `fix/calculation-bug` — виправлення помилки
- `docs/update-readme` — оновлення документації

---

## Стандарти комітів

Використовуйте Conventional Commits:

- `feat: додати новий тариф «Сім'я»`
- `fix: виправити розрахунок SMS понад ліміт`
- `docs: оновити README`
- `refactor: винести логіку розрахунку в окремий метод`
- `test: додати тести для CalculateCost`

Один коміт = одна логічна зміна. Не змішуйте форматування з функціональними змінами.

---

## Як проводити тестування

1. Зберіть проєкт:
dotnet build
2. Запустіть застосунок:
dotnet run
3. Перевірте вручну:
   - введіть різні значення ГБ / хвилин / SMS;
   - переконайтеся, що вартість у таблиці розраховується правильно;
   - перевірте, що рекомендація відповідає найдешевшому тарифу.

4. Якщо додали нову логіку — додайте відповідні тести.

---

## Як оформити Pull Request

1. Запуште свою гілку у свій форк:
git push origin feat/назва-зміни
2. Відкрийте Pull Request проти гілки `main` оригінального репозиторію.
3. У описі PR вкажіть:
   - що саме змінено;
   - який Issue це закриває (наприклад: `Closes #12`);
   - як перевірити зміни.
4. Дочекайтеся проходження CI-перевірок (якщо налаштовані).
5. Якщо є UI-зміни — додайте скріншот або коротке відео.

---

## Питання

Якщо виникли питання — створіть Issue у репозиторії.
